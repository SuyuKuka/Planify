# programmation-web

## Manuel d'utilisation

Lancez `npm ci .` dans `.../programmation-web`.

Lancez le serveur avec `node app.js`.

### Modules utilisés

`npm list` pour voir les modules utilisés.

- `express`
- `bootstrap`
- `ejs`
- `pg`

- `nodemailer`
- `express-session`
- `nodemon`
