# programmation-web

## Manuel d'utilisation

Rendez-vous au dossier `modules` sur le terminal puis lancez `npm ci`
- `.../programmation-web/modules$ nmp ci`

Cette commande va regarder les fichiers `packages.json` et `packages-lock.json` (ces fichiers donnent les infos sur les modules utilisés du projet) puis à partir de ceux-ci, va installer les bons modules.

Puis allez dans `.../programmation-web` et lancez `make`
- - `.../programmation-web$ make`
